# Jobpedia.ai portfolio website

A complete static website ready for GitHub Pages. All images and both crossfade animations are included. This package includes the latest consistent section-spacing adjustments.

## Publish on GitHub Pages

1. Unzip this archive on your computer.
2. Create a GitHub repository and upload the extracted files and the entire assets folder to its root. index.html must be at the top level, not inside another folder. Upload the extracted contents, not the ZIP itself.
3. Open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select main and / (root), then Save.
6. Wait for GitHub to finish deploying. The website address appears on the Pages screen.

No installation, build command, or ChatGPT login is required. Keep all filenames and the assets folder structure intact.

To update the website, replace the relevant files in the repository and commit the changes. GitHub Pages publishes them automatically.
